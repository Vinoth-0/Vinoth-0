### 🛠️ Featured Projects

#### 🚆 [Smart Train Reservation System](https://github.com/Vinoth-0/train-reservation-system)

A full-stack train reservation platform designed as a flagship portfolio project.

- **Backend:** Spring Boot, MySQL, JWT-based authentication
- **Frontend:** React 19, Vite, React Router DOM, Axios, CSS Modules
- **Highlights:** Journey details & route timeline UI, live seat availability table, light/dark mode support, custom blue/gold glassmorphism theme

#### 🗂️ [Employee Leave Management System](https://github.com/Vinoth-0/employee-leave-management-system)

A complete employee & leave request management system built with production-grade backend practices.

- **Backend:** Java 17, Spring Boot 3.2.0, Spring Data JPA/Hibernate, MySQL 8, Maven, Lombok
- **API Docs & Testing:** SpringDoc OpenAPI (Swagger UI), JUnit 5 + Mockito
- **Frontend:** React 19, Vite, Bootstrap 5, Axios, React Router 7, React Toastify
- **Features:** Full CRUD for employees & leave requests, pagination & sorting, centralized exception handling, DTO layer with a consistent API response wrapper
